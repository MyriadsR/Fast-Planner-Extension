【选项1】默认启动（自动打开 RViz）
  roslaunch dynamic_obstacles dynamic_cubes.launch

【选项2】不启动 RViz（仅后台节点）
  roslaunch dynamic_obstacles dynamic_cubes.launch use_rviz:=false

【选项3】自定义参数
  roslaunch dynamic_obstacles dynamic_cubes.launch \
    obs_num:=10 \
    obs_max_speed:=1.5 \
    use_rviz:=true

🐛 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【问题】RViz 打开但看不到障碍物
【解决】
  1. 检查 Fixed Frame 是否为 "world"
  2. 在 Displays 中确认 PointCloud2 和 MarkerArray 已启用
  3. 检查话题是否正确：
     rostopic list | grep dynamic

【问题】RViz 不自动打开
【解决】
  1. 确认参数：use_rviz:=true（默认已是 true）
  2. 检查 rviz 是否安装：
     rospack find rviz
  3. 手动启动 RViz：
     rosrun rviz rviz -d $(rospack find dynamic_obstacles)/rviz/dynamic_obstacles.rviz

【问题】RViz 打开后立即关闭
【解决】
  1. 检查配置文件是否存在：
     ls rviz/dynamic_obstacles.rviz
  2. 查看错误日志：
     cat ~/.ros/log/latest/rviz-*.log

【问题】只想要后台节点，不要 RViz
【解决】
  启动时加参数：
  roslaunch dynamic_obstacles dynamic_cubes.launch use_rviz:=false

📊 性能优化建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果 RViz 运行卡顿：

1. 降低点云分辨率
   resolution:=0.3  # 默认 0.2

2. 减少障碍物数量
   obs_num:=3  # 默认 5

3. 降低更新频率
   freq:=5.0  # 默认 10.0

4. 在 RViz 中：
   - 减小点云大小：Size (m) = 0.03
   - 禁用不需要的显示项
   - 降低 Frame Rate（在 Global Options）

topo_replan.launch 也已集成动态障碍物：

基本运行（包含静态+动态障碍物）：
  roslaunch plan_manage topo_replan.launch

禁用动态障碍物：
  roslaunch plan_manage topo_replan.launch enable_dynamic_obs:=false

自定义参数：
  roslaunch plan_manage topo_replan.launch \
    dynamic_obs_num:=8 \
    dynamic_obs_speed:=1.2

注意：topo_replan.launch 中的动态障碍物默认不启动 RViz
     （因为可能已有其他可视化）
